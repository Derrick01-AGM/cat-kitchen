# 猫猫回转食堂：第一关合并版

解压后，保持 `index.html`、`level1.html`、`level1.css`、`level1.js` 和 `assets` 素材文件夹在一起，双击 `index.html`（或原有 `level1.html`）即可离线运行。不需要安装软件或启动服务器。全部食材、主厨、地图均内嵌，无网络依赖。

## 开场介绍与 GitHub 上传

进入页面先显示第一关的主题与新手特色，包括四道菜、取放、切菜保留进度、自动煎炸与回转上菜。阅读时不计时，不生成顾客，也不播放音乐；点击“开始营业”后才从 180 秒启动本局。开始前点击顶部“重新开始”仍保留介绍，不能绕过开始按钮。开局后的重新开始与结算再开一局沿用原来的直接重开方式。

新增 index.html，与 level1.html 内容一致，方便 GitHub Pages 直接访问文件夹。把压缩包内的 level1 文件夹整体上传到仓库根目录，保留 level1.css、level1.js 和 assets 的相对位置。若上传后的目录为仓库根目录下的 level1，可运行地址为 https://derrick01-agm.github.io/cat-kitchen/level1/ 。

## 已确认的合并约定

- 每局 **180 秒**，采用同学版本的时长。
- 使用调整后的第一关布局与统一尺寸桌面；启用 **1 个切菜台、1 个灶台、1 个油锅、5 个备菜台、2 个垃圾桶**。
- 第一关只点单、出餐 **熟番茄、面包、汉堡、薯条**。熟肉饼只作汉堡中间材料；不加入披萨、热狗、沙拉。
- 操作、加工耗时、投掷规则、指定订单与计分以同学代码为依据；地图、食材、主厨与身前持物以 test 为依据。
- 双方原文件和 test 未被覆盖。第一关独立保存在本文件夹。

## 文件与音乐素材

- `index.html`：GitHub Pages 默认入口，内容与 level1.html 一致。
- `level1.html`：地图 SVG、页面结构、订单区域、状态栏、结算层和操作说明。
- `level1.css`：米黄色餐厅、响应式地图、订单纸、按钮与界面样式。
- `assets/bgm.m4a`：用户提供的 `real area.m4a` 原文件副本，无转码，随游戏离线读取。
- `level1.js`：地图坐标、内嵌主厨 SVG、可复用食物绘图、第一关玩法、输入、订单和绘制。

`level1.js` 保留同学熟悉的 `g` 状态以及 `interact`、`startProcess`、`doThrow`、`handleThrowLanding`、`cutItem`、`cookItem`、`tryCombine`、`update`、`draw` 等接口。配置入口是 `LEVEL`，只需修改时长、顾客耐心、出客人数等数值即可继续调试。

## 玩法

- WASD 移动；Shift 冲刺；E 拿取／放入／取走／捡起；切菜必须站在台旁按住 F，灶台／油锅放入合适材料后自动加工 1.5 秒，无需 F；Esc 结束本局。
- E 放入工具，切菜按住 F，灶台和油锅自动加工，完成后 E 取走。第一关切菜保留 **1.5 秒**，必须在切菜台旁持续按住 F；松手或走开会暂停并保留进度，回来按住 F 继续；取走或更换台上材料时清零；灶台和油锅 **按 E 放入材料后自动加工 1.5 秒，无需 F**，期间可以离开，完成后 E 拿走成品。
- 面包直接出餐；熟番茄无需再到旧装盘台加工；汉堡在任意备菜／出餐台凑齐三样食材后自动合成。
- 轻按 Q（小于 0.2 秒）放在脚下，空手 E 捡起。长按最多蓄力 1.2 秒，松手沿最后移动方向投掷，距离 60～330 游戏像素。
- 投到切菜台只放入，仍需走近并按住 F；投到灶台／油锅自动开始加工，同样需要等待进度条完成；投到备菜／出餐台可合成；投到上带口自动出餐；投到垃圾桶丢弃；其他落点成为地面食材。
- 工作台占满或食材不适用时，投掷物落到附近可捡取的空地，避免卡在桌子碰撞体里。
- 新版的 `prep1 / prep2 / prep3 / prep4 / prep5` 均支持暂存与汉堡合成；同时最多三种食材，不能重复放同一种。
- 顾客耐心 **52.5 秒**，每 **4～8 秒**尝试来一位，同时最多 **5 位**（等待和正在用餐均计入；离店后才补充新顾客），使用地图外围的 12 个固定座位。
- 顾客只取点单对应的菜，吃饭 **2 秒**后 +15 分；等太久 -5 分，最低为 0 分。
- 订单纸显示顾客头像、菜图、菜名、座位号和绿／橙／红耐心条。食堂只完成第一关，不自动跳到第二关，也未擅自设置通关分数。
- 窗口失焦会暂停并取消未松手的投掷，切回后继续，避免卡键和误扔。重新开始会清空本局数据。

## J 技能（仅接入同学的 K 技能）

- J 开启“脊背龙状态”，持续 16 秒，走路及冲刺速度均为原来的 1.8 倍；切菜、灶台煎煮和油炸速度均为 2 倍，即各需 0.75 秒；已经开始的加工也会立即享受加速。
- 冷却从发动时起计 30 秒，顶部状态栏显示生效剩余时间、冷却或可用状态。
- 保留暖色光环、背鳍及同学版本的“内阁”飘字。灶台、油锅保持常开，E 放入就开始，无需 F；切菜仍必须按住 F。
- 仅将现有脊背龙技能绑定到 J；不接入同学原来的 J、L 技能，Z、K、L 键不绑定技能；失焦暂停技能计时，重新开局重置。

## 背景音乐

- BGM 来自用户提供的 `real area.m4a`，以 `assets/bgm.m4a` 随包提供。音量固定 25%，整局循环。
- 进入游戏尝试自动播放；若浏览器限制有声自动播放，首次点击或操作键触发播放，按钮显示“点击开启音乐”。
- 音乐开关位于页面顶部，关闭后暂停音乐，重新开启从暂停处继续；静音偏好在本页面的重新开局中保留。
- 窗口失焦或标签页隐藏时暂停，回到游戏后从原位置继续；结束或 Esc 退出时停止并归零；重开从头播放。
- 音频缺失或不支持时按钮显示加载失败，游戏仍可运行。传给同学时必须发送完整压缩包并解压，不能只发送三个代码文件。

## 地图与画面适配

逻辑地图是 **1440 × 960**，Canvas 随背景等比例显示，碰撞、站点、地面食材和投掷均使用这一坐标。所有桌面统一缩放为 0.7，碰撞尺寸相同。上方七张桌子以 x=720 为中心等距对称排列，从左至右：番茄箱、土豆箱、肉饼箱、面包箱、切菜台、灶台、油锅。下方从左至右：备菜1、备菜2、备菜3、备菜4、备菜5、放传送带。左右两侧是图标和功能一致的垃圾桶。上带通道与出餐口同步移动。

食物沿真实的 SVG 圆角路径移动；上带位置固定在出餐口；每个固定座位投影到同一条路径，按食物经过座位的顺序交付。主厨继续使用空手／持物两张矢量底图和前后分层的前爪。

## 修正的接入问题

- 原玩法按每帧固定像素移动，已换算成每秒速度，消除刷新率差异。本轮将常速从 180 提至 **207**、冲刺从 330 提至 **380**，均提高约 15%。配置入口为 `LEVEL.walkSpeed / sprintSpeed`。
- 原玩法用极角算上带进度，但传送带按矩形周长绘制，现统一为 SVG 路径的投影和长度。
- 接入桌面碰撞，减少后厨穿桌；不同桌面距离较近时，按可互动范围内最近的站点选择。
- 加工中的工具不能再次放入或取走；台面上限三样与投掷规则一致，防止重复堆放造成状态丢失。
- 地面食物优先拾取，投掷落点不适用时可恢复；长按 Q 期间不再同时更换手中食物。
- 订单纸按顾客 ID 更新，不再每帧全部重建。
- 180 秒结束和 Esc 退出后停止本局操作，并提供重新开始按钮。

## 本轮性能优化

- 固定工作台、工具、文字合成到缓存层；只有放入／拿走食材、合成或加工状态改变时才重画，切菜进度条单独更新。
- 食物、顾客头像、主厨底图缓存为小贴图，不再每帧重复绘制同样的矢量路径；贴图按双倍像素生成，保留缩小显示时的清晰度。
- HUD 只有数值或提示发生变化才改写；订单耐心条约每秒更新 10 次，用缩放替代反复改变宽度。
- 站点查找和传送带交付减少临时数组、排序；Canvas 独立绘制层；暂停和结算后不再连续重画相同画面。
- 传送带的运动分隔线移入 Canvas，仅绘制这一条运动路径；背景 SVG 不再运行描边动画，减少整张餐厅背景的重绘。
- 角色移动、传送带运动和投掷动画仍逐帧更新。没有降低游戏分辨率、删减食材图案或减少顾客数量。

此前 v2 的本地原生 Canvas 基准（非当前顾客上限）：1440×960、8 位顾客、12 份传送带菜、10 件地面物品、13 个工作站，预热后各测两轮。优化前每帧平均约 8.67 毫秒，优化后约 4.04 毫秒，耗时减少约 53%。该测试不包含浏览器页面布局和背景 SVG 的绘制，不能等同于真实浏览器 FPS。
