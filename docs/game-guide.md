## 一、整体玩法

《小猫厨房》是一款基于 HTML5 Canvas + 原生 JavaScript 的 2D 单机经营小游戏。玩家扮演小猫主厨，在限定时间内完成顾客订单。

三关共用一套核心循环：

**看订单 → 取食材 → 加工 → 上菜 → 得分**

### 1. 核心流程

- **取食材**：靠近食材箱、水池或捕鱼网，按 `E` 拿取。
- **加工**：
  - 切菜台：按住 `F` 切片，松手或离开会暂停并保留进度。
  - 灶台、油锅、高压锅、烧烤架、生腌区等：按 `E` 放入合适材料后自动加工。
  - 备菜台 / 推车格：最多放 3 样，满足配方自动合成。
- **上菜**：
  - 第一、二关：把成品放上回转带，送到顾客面前自动取走。
  - 第三关：把成品放入对应推车的出餐位或推车格，对应队列有人点这道菜即可出餐。
- **得分**：顾客取餐后约 3 秒离开，`+15` 分；耐心耗尽离开 `-5` 分，最低 0 分。

### 2. 三关差异

| 关卡 | 主题 | 内容 |
|---|---|---|
| 第一关 | 猫猫回转食堂 | 新手练习关，中央厨房 + 回转带，4 道家常菜 |
| 第二关 | 浮木小厨房 | 海上日料，8 道海鲜料理，有捕鱼网和鲨鱼机制 |
| 第三关 | 猫猫风味街 | 300 秒挑战，三辆推车分别做小吃、日料、甜品饮品，共 16 道菜；有巡逻猫和过街取车机制 |

### 3. 通用操作

| 按键 | 功能 |
|---|---|
| `W A S D` | 移动 |
| `Shift` | 冲刺 |
| `E` | 拿取 / 放下 / 交互 / 出餐 / 拖车 |
| 按住 `F` | 切菜 |
| `Q` | 轻按放下，长按蓄力投掷 |
| `P` | 暂停（第二、三关） |
| `Esc` | 退出本局 |

## 二、第二关特殊机制

- **捕鱼网**：空手 `E` 下网，约 5 秒后回来 `E` 逐只取走 3–4 份海鲜；取完才能再次下网。
- **顾客送海鲜**：顾客入座后会送来对应海鲜，补充原料。
- **鲨鱼红圈**：随机出现红圈预警，跳起清空范围内加工中的食材和已做好的菜；小猫在范围内会被吓晕。
- **吓晕苏醒**：被吓晕后连续轻按空格可加快恢复。
- **投食诱鲨**：把食物蓄力扔进海里，可引开鲨鱼约 15 秒；诱饵冷却 60 秒。
- 切菜松手或离开会暂停并保留进度；锅具、烧烤架、生腌区放入材料后自动加工，可以离开。

## 三、第三关特殊机制

- **三辆推车**：上方小吃、中间日料、下方甜品饮品；每车 4 个摆盘位，可暂存食物，也可合成对应菜品，材料须放在同一推车同一格。
- **出餐规则**：对应队列有人点这道菜即可出餐，无需按排队顺序；没人点的菜不能出餐。
- **顾客**：同时最多 7 位，每队最多 3 位；耐心 52.5 秒，超时离开 `-5` 分；取餐 3 秒后离开 `+15` 分。
- **巡逻猫扣车**：车上食物或顾客尚未带走的餐点被发现，会触发扣车并清空食物，顾客留在原位继续排队。
- **过街取车**：空手到暂扣位按 `E` 拖车，回原车位自动归还；注意车辆，撞车眩晕约 1.8 秒。
- **投掷**：轻按 `Q` 放下；长按 `Q` 蓄力投掷，最多 1.2 秒、60～330 像素；绿色表示可接收，红色表示不可接收，金色表示落地。

## 四、三关技能介绍

| 关卡 | 技能 | 按键 | 效果 | 冷却 |
|---|---|---|---|---|
| 第一关 | 脊背龙 | `J` | 16 秒内移动/冲刺 ×1.8，切菜、煎煮、油炸 ×2（约 0.75 秒完成） | 30 秒 |
| 第二关 | 脊背龙 | `J` | 16 秒内移动/冲刺 ×1.8，加工 ×2 | 30 秒 |
| 第二关 | 老吴 | `K` | 当前顾客暂停耐心和送货计时 5 秒 | 30 秒 |
| 第二关 | 空格加速苏醒 | `空格` | 被鲨鱼吓晕后连续轻按，加快恢复 | — |
| 第三关 | 脊背龙 | `J` | 16 秒内移速 ×1.8，加工 ×2 | 30 秒 |
| 第三关 | 老吴 | `K` | 冻结顾客与巡逻猫 5 秒 | 30 秒 |
| 第三关 | 小猫哈气 | `L` | 取消巡逻预警或驱赶巡逻猫 | 40 秒 |

## 五、总结

《小猫厨房》以“小猫经营餐车/餐厅”为主题，通过三关递进设计，让玩家从简单取料上菜，逐步接触切菜、烹饪、合成、捕鱼、躲避鲨鱼、管理推车、应对巡逻猫等机制。整体操作轻量，节奏紧凑，适合休闲娱乐时游玩
