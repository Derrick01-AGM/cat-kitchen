# 浮木小厨房 · 第二关整合版

页面下方现已直接展开八道菜的制作方法，向下滚动即可查看。

## 打开和转交

解压整个 level2 文件夹，双击 index.html，在浏览器中点击“开始营业”。
三个代码文件需保持在同一文件夹：index.html、style.css、game.js。
美术已包含在代码中，背景音乐位于 assets/bgm.m4a。请保留 assets 文件夹并一起解压；无需联网，也不用安装依赖。请把整个压缩包发给同学，不要在聊天软件的代码预览窗口里试玩。
原 level2-test、level1 均保留。文件夹里原有的 layout-sketch.png 只是旧草图，不参与游戏运行。

技能文字效果：J 生效的 16 秒内，主厨头顶会连续冒出向上飘动的“内阁”；K 触发时，主厨上方会弹出放大的“老吴”，随后淡出。

## 背景音乐

使用提供的 sea sound.m4a，默认音量 50%，整局单曲循环。点击“开始营业”后播放；切出窗口、手动暂停时音乐暂停，返回或继续时从原位置接着播放；结束或退出停止并回到开头，重开从头播放。右上方“音乐：开/关”可随时静音，静音选择在本次页面内的重开中保留。若浏览器拦截播放，点击音乐开关即可开启。

眩晕提示现使用更大的提示框，附带剩余时长进度条；时间流逝或连续轻按空格都会使进度条同步缩短，恢复后提示消失。

## 中央随机捕鱼池

浮木中央新增小水域，直接透出外海的同一层水色和水波。水池上下均保留横向通道，左右仍能绕行，全部原有工作台和传送带接货位置保持可达。

两张捕鱼网规则完全相同：靠近后空手按 E 下网，自动捕捞约 5 秒，期间可以离开做菜；完成后每网获得 3～4 份随机海鲜。每一份都独立从鱼、虾、蟹、鱿鱼中随机抽取，允许重复或混合，不按网绑定种类。空手 E 一次取走一份，取完后再按 E 开始下一网。手里有食材时不会误取或覆盖。

两网独立运行；游戏暂停、切出窗口时捕鱼计时一起暂停。网中已捕到的海鲜处于鲨鱼攻击范围内时会被清空，网本身保留；尚在进行的捕鱼可继续完成。重开会清空两网。顾客送货、八道菜、技能、音乐和计分继续保留。

## 工作台辨识配色

烤箱为暖红色，油锅为金黄色，高压锅为灰蓝色，切菜台为浅绿色，生腌区为淡紫色，垃圾桶为灰绿色；备菜台维持奶油色、食材箱维持木色。各类台面带对应的淡色底，名称改为更深的棕色并略加粗。

## 本次合并规则

- 地图、双排共 15 张工作台、主厨、食物和工具采用 level2-test 的画面。
- 保留 8 道菜：三文鱼寿司、天妇罗、生腌虾、生腌蟹、三文鱼刺身、烤鱼、烤鱿鱼、炙烤虾寿司。
- 顾客采用第一关的六种猫咪样貌，订单挂在画面上方；每个座位只坐一位顾客。
- 沿用同学版：180 秒一局，顾客最多 5 位，耐心 52.5 秒，每 3 秒尝试入座一位，吃完加 15 分，等不及离开扣 5 分。
- 海鲜有两个来源：中央随机捕鱼网，以及顾客送货。顾客仍在入座 3 秒后给对应订单送来一份海鲜；每单送一次。
- 按讨论确认：切菜中断保留进度，配方材料必须放在同一张备菜台。
- 按讨论确认：鲨鱼保留圆形预警和范围清除，浮木完整，不再死亡或传送复活。范围内台面、地面和传送带食物会消失，命中的主厨原地眩晕 5 秒，手持食物消失。
- 整个浮木场景随水波轻微摆动，人物、工作台和食物同步，动画不会改变碰撞或交互距离；系统选择减少动态效果时停用浮木摆动。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Shift | 按住冲刺 |
| E | 拿取、放下、接顾客海鲜、将食物直接放上回转带 |
| 按住 F | 站在切菜台旁空手切鱼；松手或离开即暂停，回来继续 |
| Q 轻按，小于 0.2 秒 | 食物放脚下，空手 E 捡回 |
| Q 长按，松开 | 沿最后移动方向投掷，最多蓄力 1.2 秒，距离 60～330 地图像素 |
| J | 脊背龙：16 秒内移动 ×1.8、所有加工 ×2，冷却 30 秒 |
| K | 老吴：当前等待顾客的耐心和送货倒计时暂停 5 秒，冷却 30 秒 |
| 连续轻按空格 | 眩晕时每次按下减少 0.3 秒；长按不连续扣减 |
| P / 暂停按钮 | 暂停、继续整局 |
| R / 重新开始按钮 | 从头开一局 |
| Esc / 退出本局按钮 | 停止本局，显示重新开始入口 |

离开窗口自动暂停，回到窗口继续；手动暂停需主动继续。

投掷可把合适的材料送上工作台或回转带。投入真实海水的食物可作诱饵，吸引鲨鱼停止攻击 15 秒，诱饵冷却 60 秒；冷却期间投海的食物会被其他鱼吃掉。烤箱、高压锅、油锅和生腌区收到材料即自动工作，切菜台仍需主厨按住 F。

## 菜谱与时间

| 成品 | 做法 |
| --- | --- |
| 三文鱼刺身 | 生鱼放切菜台，在旁边按住 F 切 1.5 秒 |
| 三文鱼寿司 | 刺身＋熟米饭＋海苔，放同一备菜台自动合成 |
| 天妇罗 | 生虾＋面糊，同一备菜台合成裹粉虾，再放油锅炸 2 秒 |
| 生腌虾 | 生虾放生腌区，3 秒完成 |
| 生腌蟹 | 生蟹放生腌区，3 秒完成 |
| 烤鱼 | 生鱼放烤箱，3 秒完成 |
| 烤鱿鱼 | 生鱿鱼放烤箱，3 秒完成 |
| 炙烤虾寿司 | 生虾放烤箱烤 3 秒，再和熟米饭、海苔放同一备菜台 |

熟米饭：米箱取生米，放高压锅自动煮 2.5 秒。海苔、面糊直接拿取。
加工时间参考同学版；脊背龙期间时间减半。刺身既可直接上菜，也可继续做寿司。

## 后续修改入口

- game.js 顶部 CONFIG：移动速度、工作台加工时间、鲨鱼预警及范围。
- game.js 中 RULES：局时、顾客耐心、得分、技能持续/冷却和投掷参数。
- SEAFOOD_FOR：每种订单由顾客送来的生海鲜。
- PREP_RECIPES / OVEN_RECIPES：配方。
- topStations / bottomStations：上下两排工作台。
- style.css：页面、订单纸、按钮和界面排版。
- raftPose：浮木摆动幅度。
