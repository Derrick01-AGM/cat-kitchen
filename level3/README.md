# 小猫厨房 · 第三关

直接打开 index.html；交接或上传时，请将 index.html、style.css、game.js、sfx.js、grill.js 与 assets 文件夹一起保留。

BGM：The Process，默认音量30%，开始营业后循环播放。暂停或切出窗口时暂停音乐，回来后按当前游戏状态继续；退出或本局结束时停止，重新开始从头播放。右上角可开关音乐。

本版采用最新 level3-test 的地图、统一切菜板和 16 道菜；保留杯子、五杯容量茶壶与切菜进度。每局 300 秒。顾客开局为空，首位5秒后到达，后续每4～8秒随机来一位，同时最多7位、每队最多3位。菜品随机，按菜系分流；不按队首顺序出餐。每位耐心52.5秒，超时扣5分，分数可为负；收到餐后停止消耗耐心。开始按钮之前不计时；暂停与切出窗口都会冻结游戏。

操作：WASD / 方向键移动，Shift 冲刺，E 拿放/出餐/拖车，按住 F 切菜，轻按 F 煮茶，Q 轻按放下、长按蓄力投掷，P 暂停、Esc 退出本局。

Q 蓄力时显示虚线路径和落点：绿色表示工作台可接收，红色表示被占用或配料不兼容，金色表示落在地上。松手后会由沿途适合的工作台接住；切菜台仍需按住 F，加热机器自动开始。目标在飞行中变满时，食材保留在附近地面，可按 E 捡回。

J 脊背龙：16 秒移动 ×1.8、制作 ×2，冷却 30 秒。K 老吴：冻结顾客和城管 5 秒，冷却 30 秒。L 小猫哈气：取消预警或沿斑马线驱赶城管，冷却 40 秒。

城管采用原地图巡逻路线，正常移动 150 像素/秒；首轮等待12秒、预警3秒，结束后随机等待18～33秒，哈气驱赶后等待25～40秒。

同一辆推车的四个摆盘格各自独立；所有备菜配方及杯装饮品必须把材料放到同一格才会合成，不会跨格取料。空手按 E 可逐份取回未合成的材料。车上暂存食物和顾客尚未带走的食物都会触发扣车。扣车清空这些食物；顾客留在原地保留订单，并继续消耗此前剩余的耐心。空手到对面暂扣位按 E 拖车，返回对应车位自动归还。

顾客取餐需3秒，带走后+15分；冻结期间不取餐。撞车眩晕1.8秒并有击退、闪烁、星星及剩余进度提示，肇事车停车3秒后移除。

所有图片绘制和主厨素材包含在本地代码中，不需要额外下载素材或联网。
